# Original Experiment A pilot summaries

These four files are unchanged outputs of the original 28 October 2026 pilot:
100 cells × 200 replications, 20,000 cell-replications and 420,000 method/alpha
decisions. They describe their original source identity, not the current code.
No simulation was rerun during housekeeping. The external original pilot and
its manifests remain unchanged. Read the [original interpretation](../../../docs/Experiment_A_Pilot_Summary.md)
and [research protocol](../../../docs/Monte_Carlo_Research_Protocol.md) for scope,
pointwise uncertainty and limitations.
